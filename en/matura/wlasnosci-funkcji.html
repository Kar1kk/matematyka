The concept of a function and its properties (reading from a graph)

A function assigns to each argument exactly one value. Almost everything the exam asks about can be read from the graph by projecting it onto the axes: the $Ox$ axis shows arguments, the $Oy$ axis shows values.

V.1–V.4

1. What a function is

Definition A function $f\colon X\to Y$ assigns to each element $x\in X$ exactly one element $f(x)\in Y$. The set $X$ is the domain ($D_f$), and the set of all values taken is the range ($\operatorname{range} f$).

A function can be given by a verbal description, a table, a graph (diagram), a plot, or a formula – also by different formulas on different intervals:

Piecewise function
$$f(x)=\begin{cases} x+3, & x<-1\\ x^2-1, & x\ge -1\end{cases}$$
$f(-2)$
$-2<-1$, so the first formula: $f(-2)=1$
$f(2)$
$2\ge-1$, so the second formula: $f(2)=3$
If a formula contains a fraction, a root or a logarithm and no domain is given, the domain is all $x$ for which the formula makes sense: denominator $\neq0$, under an even-degree root $\ge0$, under a logarithm $>0$.

Definition A function $f$ is increasing on a set $A$ if for any $x_1,x_2\in A$: $$x_1<x_2\ \Rightarrow\ f(x_1)<f(x_2).$$ Decreasing: $f(x_1)>f(x_2)$. Non-decreasing: $f(x_1)\le f(x_2)$, non-increasing: $f(x_1)\ge f(x_2)$, constant: $f(x_1)=f(x_2)$.
Do not join intervals of monotonicity with the symbol $\cup$. The function in the demo decreases on $[-6,-4]$ and on $[1,5]$, but it does not decrease on their union: $-6<1$, yet $f(-6)=2<f(1)=4$.

5. Step-by-step example

Find the zeros and the range of the function $f$ from section 1 (the piecewise formula).

  1. For $x<-1$: $x+3=0 \iff x=-3$, and $-3<-1$, so this is a zero.
  2. For $x\ge-1$: $x^2-1=0\iff x=\pm1$. Both satisfy $x\ge-1$, so both count.
  3. Values: for $x<-1$ we have $x+3<2$, that is $(-\infty,2)$. For $x\ge-1$: $x^2\ge0$, so $x^2-1\ge-1$, that is $[-1,\infty)$.
  4. The union $(-\infty,2)\cup[-1,\infty)=\R$.

Zeros: $-3,\ -1,\ 1$; $\;\operatorname{range} f=\R$

Trap: for every formula check that the $x$ you found lies in its interval.

6. Tasks

  1. easy
    Find the domain of $f(x)=\sqrt{x+5}-2x$ and compute $f(4)$.
    Solution
    $x+5\ge0\iff x\ge-5$. $f(4)=\sqrt9-8=3-8$. $D_f=[-5,\infty)$, $f(4)=-5$
  2. easy
    For the function in the demo in section 4, give the set of all $x$ for which $f(x)\ge2$.
    Solution
    The line $y=2$ meets the graph at $x=-2$ and $x=2$ (the segments $y=2x+6$ and $y=-2x+6$). Between them the graph is above the line. But there is also the left endpoint: $f(-6)=2$, and further on the graph drops below the line. That is a single point. $\{-6\}\cup[-2,2]$
  3. medium
    Find the zeros of $f(x)=\begin{cases}2x+4, & x\le-1\\ x^2-2x-1, & x>-1\end{cases}$
    Solution
    $2x+4=0\iff x=-2\le-1$ ✓. $x^2-2x-1=0$: $\Delta=8$, $x=1\pm\sqrt2$. Since $1-\sqrt2\approx-0.41>-1$, both fit. $x\in\{-2,\ 1-\sqrt2,\ 1+\sqrt2\}$
  4. medium
    For the function in the demo in section 4, give the largest and smallest value on the interval $[-5,3]$ and the arguments at which they are attained.
    Solution
    Values at the endpoints and at the break points: $f(-5)=0$, $f(-4)=-2$, $f(-1)=f(1)=4$, $f(3)=0$. The largest is $4$ for every $x\in[-1,1]$, the smallest is $-2$ for $x=-4$. Check in the demo: $a=-5$, $b=3$.
  5. exam-level
    The function $f(x)=x^2-6x+5$ has domain $[0,5]$. Give its range and determine the number of solutions of $f(x)=m$ depending on $m$.
    Solution
    The vertex is $W=(3,-4)$, $f(0)=5$, $f(5)=0$, so $\operatorname{range} f=[-4,5]$. The line $y=m$ meets the graph (an arc from $(0,5)$ through $W$ to $(5,0)$): twice when $-4<m\le0$; once when $m=-4$ or $0<m\le5$; never outside $\text{range}$. 2 solutions for $m\in(-4,0]$; 1 for $m=-4$ or $m\in(0,5]$; 0 for $m<-4$ or $m>5$.

7. On the exam

  • Open and filled dots at the ends of a graph decide the brackets: filled $[\ ]$, open $(\ )$. The most common lost point.
  • Give monotonicity as separate intervals, never as a union. You may close the endpoints if they belong to the domain.
  • The largest value is a number ($y$), while the argument at which it is attained is $x$. Read what they ask for.
  • For $f(x)\ge c$ check isolated points (the end of the domain, a vertex touching the line $y=c$).
  • Piecewise function: a solution from each formula must lie in its interval.
