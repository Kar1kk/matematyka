Intervals

An interval is the set of all numbers between two endpoints. On the number line it is drawn as a thick segment, and the endpoints as a filled dot (included) or an open dot (not included).

1. Types of intervals

Definition An interval is the set of all real numbers satisfying a condition on the position relative to two numbers $a$ and $b$ (where $a<b$).
NotationInequalityDescriptionDrawing on the line
$(a, b)$$a < x < b$open intervala line with open dots at $a$ and $b$, a thick segment between them
$[a, b]$$a \le x \le b$closed intervala line with filled dots at $a$ and $b$, a thick segment between them
$[a, b)$$a \le x < b$closed on the leftfilled dot at $a$, open at $b$
$(a, b]$$a < x \le b$closed on the rightopen dot at $a$, filled at $b$
Infinite intervals
  • $(-\infty, a) = \{x \in \R : x < a\}$
  • $(-\infty, a] = \{x \in \R : x \le a\}$
  • $(a, +\infty) = \{x \in \R : x > a\}$
  • $[a, +\infty) = \{x \in \R : x \ge a\}$
  • $(-\infty, +\infty) = \R$
A filled dot means the number belongs to the interval ($\le$ or $\ge$). An open dot means it does not belong ($<$ or $>$).

3. Operations on intervals

Union of intervals $A \cup B$ is the set of all numbers that belong to $A$ or to $B$ (or to both).
Intersection $A \cap B$ is the set of all numbers that belong to $A$ and to $B$ at the same time.
Difference of intervals $A \setminus B$ is the set of numbers in $A$ that do not belong to $B$.
Complement of an interval $A' = \R \setminus A$ is the set of all real numbers that do not belong to $A$.

Let $A = [-2, 3]$ and $B = (1, 5)$. Find $A \cup B$, $A \cap B$ and $A \setminus B$.

  1. Union: We join both intervals. From $-2$ (closed) to $5$ (open): $A \cup B = [-2, 5)$
  2. Intersection: The part where they overlap: from $1$ (open, because $B$ is open) to $3$ (closed, because $A$ is closed): $A \cap B = (1, 3]$
  3. Difference $A \setminus B$: From $A$ we remove what is in $B$. $B$ starts at $1$ (open), so we remove $(1, 3]$. What remains is $[-2, 1]$ (because $1$ does not belong to $B$, so it stays in the difference).

$A \cup B = [-2, 5)$, $A \cap B = (1, 3]$, $A \setminus B = [-2, 1]$

4. Step-by-step example

Mark on the number line and write as an interval the set $( -3, 2] \cup [1, 4)$.

  1. The first interval: from $-3$ (open) to $2$ (closed).
  2. The second interval: from $1$ (closed) to $4$ (open).
  3. The two intervals overlap: the first ends at $2$, the second starts at $1$. Since $1 < 2$, there is an intersection.
  4. The union starts at $-3$ (open, because the first interval is open) and ends at $4$ (open, because the second interval is open).

$( -3, 2] \cup [1, 4) = ( -3, 4)$

5. Tasks

  1. easy
    Write as an interval the set of all numbers $x$ satisfying $-3 \le x < 5$.
    Solution
    The left endpoint $-3$ belongs (sign $\le$), the right endpoint $5$ does not belong (sign $<$). $[-3, 5)$
  2. easy
    Mark the interval $( -2, 3]$ on the number line.
    Solution
    On the line we draw a thick segment from $-2$ to $3$. At the point $-2$ an open dot (open endpoint), at the point $3$ a filled dot (closed endpoint).
  3. medium
    Given the intervals $A = (-4, 1]$ and $B = [-1, 3)$, find $A \cap B$ and $A \cup B$.
    Solution
    $A \cap B$: from $-1$ (closed, because $-1$ belongs to both intervals) to $1$ (closed, because $1\in A$ and $1\in B$): $[-1, 1]$
    $A \cup B$: from $-4$ (open) to $3$ (open): $(-4, 3)$
    $A \cap B = [-1, 1]$, $A \cup B = (-4, 3)$
  4. medium
    Find the difference of intervals $( -5, 4] \setminus [0, 2]$.
    Solution
    From the interval $( -5, 4]$ we remove all numbers from $[0, 2]$.
    What remains: from $-5$ (open) to $0$ (open, because $0$ belongs to the removed interval) and from $2$ (open, because $2$ belongs to the removed one) to $4$ (closed).
    $( -5, 0) \cup (2, 4]$
  5. exam-level
    The complement of an interval $A$ is the set $(-\infty, -2] \cup (3, +\infty)$. Find the interval $A$.
    Solution
    The complement $A' = (-\infty, -2] \cup (3, +\infty)$ means that the numbers $x \le -2$ and $x > 3$ do not belong to $A$.
    So $A$ contains all numbers between $-2$ and $3$, except those that are already in the complement.
    $-2$ belongs to the complement (closed), so it does not belong to $A$. $3$ does not belong to the complement (open), so it belongs to $A$.
    $A = (-2, 3]$

6. On the exam

  • Always pay attention to the type of endpoints: filled vs. open dots decide whether a number belongs to the interval. For a union/intersection this is crucial.
  • On the number line: filled dot = square bracket $[$ or $]$, open dot = round bracket $( $ or $) $.
  • When combining intervals: if the endpoints touch (e.g. $A = (1, 3)$ and $B = [3, 5)$), then in the union the point $3$ belongs, if it belongs to at least one interval.
  • Infinite intervals: always written with a round bracket at $\pm\infty$, because infinity is not a number and cannot be "closed".
