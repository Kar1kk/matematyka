Linear equations and inequalities

To solve $ax+b>c$ is to find where the line $y=ax+b$ lies above the level $y=c$. The only real trap: dividing by a negative number reverses the inequality sign.

III.1, III.2, III.3

1. Equivalent transformations

Definition Two equations (inequalities) are equivalent if they have the same solution set. We solve by moving along a chain of $\iff$ to a simpler and simpler form.
Operation on both sidesEquationInequality
adding the same number or expressionOKOK
multiplying by a number $k>0$OKOK
multiplying by a number $k<0$OKsign reverses
multiplying by $0$ or an expression containing $x$dangerous: it may add or lose solutions
Multiplying by an expression containing $x$ (e.g. a denominator)? First assume it is nonzero. An example from the core curriculum: $\frac{5}{x+1}=\frac{x+3}{2x-1}$ with $x\neq-1$, $x\neq\frac12$ is equivalent to $5(2x-1)=(x+3)(x+1)$, that is $x^2-6x+8=0$, so $x\in\{2,4\}$.

2. Three cases: one, none, all

The equation $ax=b$
$a\neq0$
one solution $x=\frac{b}{a}$
$a=0,\ b\neq0$
$0=b$: contradictory, solution set $\varnothing$
$a=0,\ b=0$
$0=0$: an identity, solution set $\R$
The inequality $ax>b$
$a>0$
$x>\frac{b}{a}$
$a<0$
$x<\frac{b}{a}$ (the sign reverses)
$a=0$
$0>b$: if $b<0$, then $\R$ (identity); if $b\ge0$, then $\varnothing$ (contradictory)

Geometrically: the line crosses the level $y=c$ at one point or, when $a=0$, it is parallel to it (no intersection) or coincides with it (every $x$).

5. Worked example

Solve the inequality $2-\frac{x+3}{2}\ge\frac{2x+5}{3}$.

  1. Multiply by $6>0$ (the sign stays): $12-3(x+3)\ge2(2x+5)$.
  2. $3-3x\ge4x+10 \iff -7x\ge7$.
  3. Divide by $-7<0$, reverse the sign: $x\le-1$.

$x\in(-\infty,-1]$

Solve $\frac{x+1}{2}-\frac{x-2}{3}\le\frac{x+3}{6}$.

  1. Times $6$: $3x+3-2x+4\le x+3$, that is $x+7\le x+3$.
  2. The $x$ cancels: $7\le3$, false for every $x$.

A contradictory inequality: $\varnothing$. (With the sign $>$ it would be an identity: $\R$.)

6. Tasks

  1. easy
    Solve the inequality $3-2x>7$.
    Solution
    $-2x>4$, divide by $-2$ and reverse the sign: $x<-2$, that is $x\in(-\infty,-2)$.
  2. easy
    Which of the equations is contradictory and which is an identity: (A) $2(x+1)=2x+3$, (B) $3(x-2)+x=4x-6$?
    Solution
    (A) $2x+2=2x+3 \iff 2=3$: false. (B) $4x-6=4x-6$: true for every $x$. (A) contradictory, (B) identity.
  3. medium
    Find the smallest integer satisfying the inequality $\frac{2x-1}{3}-\frac{x+2}{4}>1$.
    Solution
    Times $12$: $8x-4-3x-6>12 \iff 5x>22 \iff x>4.4$. The smallest integer: $5$.
  4. medium
    For which $m$ is the equation $(m^2-4)x=m-2$ contradictory, and for which is it an identity?
    Solution
    The coefficient of $x$ vanishes for $m=\pm2$. For $m=2$: $0\cdot x=0$, an identity. For $m=-2$: $0\cdot x=-4$, contradictory. For the other $m$: $x=\frac{1}{m+2}$. Contradictory for $m=-2$, an identity for $m=2$.
  5. exam-level
    Solve the inequality $(1-\sqrt3)\,x<2$. Write the result with no irrationality in the denominator.
    Solution
    $1-\sqrt3<0$, so when dividing we reverse the sign: $x>\frac{2}{1-\sqrt3}=\frac{2(1+\sqrt3)}{1-3}=-1-\sqrt3$. $x\in(-1-\sqrt3,+\infty)$

7. On the exam

  • Sign of the coefficient: with $\sqrt3-2$, $1-\sqrt2$, $-m^2-1$ check the sign before you divide. This is the most common mistake.
  • Answer as a set: an interval with the correct brackets; $\varnothing$ for a contradictory one, $\R$ for an identity (not “none” or “all”).
  • Fractions: multiply by the common denominator and put numerators in parentheses: $-\frac{x-2}{3}$ gives $-(x-2)$.
  • With a parameter: always treat separately the case in which the coefficient of $x$ is zero.
