The multiplication and addition rules

Every count is building an object: in stages (then you multiply) or in disjoint cases (then you add). The whole art is choosing a good order of stages and a good split into cases.

XI.1, XI.2

1. Two rules and the complement

Multiplication rule
$$N=k_1\cdot k_2\cdot\ldots\cdot k_m$$
$k_i$
the number of possibilities in the $i$-th stage. It may depend on how many elements have already been chosen (e.g. $9,8,7$), but not on which ones were chosen
Addition rule (disjoint cases)
$$|A\cup B|=|A|+|B|,\quad A\cap B=\emptyset$$
$A, B$
cases that do not overlap (e.g. “last digit $0$” and “last digit $\ne 0$”)
Subtracting the complement
$$|A|=|\Omega|-|A'|$$
$A'$
objects that do not satisfy the condition. Use it with “at least one”
If the number of options in some stage depends on an earlier choice (e.g. whether $0$ stands at the end), the multiplication rule does not work directly. Split into cases and add.

The multiplication and addition rules are not on the formula sheet (they are common sense). Ready-made formulas (permutations, variations, combinations) are on the sheet: see Permutations, variations, combinations and the summary in classical probability.

2. Interactive: the choice tree

Set the number of stages and the number of options in each stage, then click ▶. Each path from the root to a leaf is one outcome. At each level the number of nodes is multiplied by the number of options.

3. The “boxes” method

  1. Draw as many boxes as the object has places (e.g. 4 digits).
  2. Start with the boxes that have conditions (first digit $\ne 0$, last digit odd…), and only then fill in the rest.
  3. When the number of options depends on an earlier choice, split into cases and add the results.
  4. “At least one…”: count all and subtract those that do not satisfy the condition.

Choose a condition and click ▶. The small numbers above the boxes show the order of filling. For even numbers with distinct digits you must split into two cases, because a zero at the end changes the number of options for the first digit.

4. Step-by-step example (from the core curriculum)

How many four-digit odd numbers are there that contain exactly one digit $1$ and exactly one digit $2$?

  1. The last digit is odd. Whether it is $1$ changes the rest, so there are two cases. The “other digits” are $0,3,4,\ldots,9$: there are $8$ of them.
  2. Last digit $=1$. The $2$ stands in one of the first 3 places. $2$ at the start: two free places, $8\cdot 8=64$. $2$ in the 2nd or 3rd place: the first digit is $\ne 0$, so $7$ options, the free place $8$: $2\cdot 7\cdot 8=112$. Total $176$.
  3. Last digit $\in\{3,5,7,9\}$ ($4$ options). In the first 3 places stand $1$, $2$ and one “other” digit. Arranging $1$ and $2$: $3\cdot 2=6$ ways. In 2 of them the “other” digit stands at the start (then $7$ options), in 4 it does not (then $8$): $2\cdot 7+4\cdot 8=46$. Total $4\cdot 46=184$.
  4. The cases are disjoint, so you add: $176+184$.

$360$ numbers

The result was verified by computer (going through all $9000$ four-digit numbers). The second example from the curriculum (even numbers with one $0$ and one $1$) is in task 6.

5. Tasks

  1. easy
    How many four-digit PIN codes are there (digits $0$–$9$, $0$ may be first)? How many of them have all digits distinct?
    Solution
    Each place: $10$ options, so $10^4$. Distinct digits: $10\cdot 9\cdot 8\cdot 7$. $10000$ codes, including $5040$ with distinct digits.
  2. easy
    How many four-digit numbers contain at least one digit $7$?
    Solution
    In total: $9\cdot 10^3=9000$. Without a seven: the first digit from $8$ (not $0$ or $7$), the others from $9$: $8\cdot 9^3=5832$. $9000-5832=3168$
  3. medium
    How many three-digit numbers with distinct digits are divisible by $5$?
    Solution
    The last digit is $0$ or $5$, and this changes the options for the first digit. Last $0$: $9\cdot 8=72$. Last $5$: first digit $\ne 0, 5$, so $8$, middle digit $8$: $64$. $72+64=136$
  4. medium
    How many four-digit numbers contain exactly two digits $5$?
    Solution
    Case 1: a five at the start. The second five in one of 3 places, two free places with $9$ options each: $3\cdot 81=243$. Case 2: both fives in places 2–4 ($3$ ways), first digit $\ne 0, 5$ ($8$), free place $9$: $3\cdot 72=216$. $243+216=459$
  5. medium
    How many positive integers less than $1000$ have all digits distinct?
    Solution
    Addition rule over the number of digits. One-digit: $9$. Two-digit: $9\cdot 9=81$. Three-digit: $9\cdot 9\cdot 8=648$. $9+81+648=738$
  6. exam-level
    (Example from the curriculum) How many four-digit even numbers contain exactly one digit $0$ and exactly one digit $1$?
    Solution
    The “other” digits: $2,\ldots,9$, there are $8$ of them. The last digit is even: cases “$0$ at the end” and “$2,4,6,8$ at the end”.
    Last digit $0$. The $1$ in one of the first 3 places, two free places with $8$ options each (the zero is already used, so the start is safe): $3\cdot 64=192$.
    Last digit $\in\{2,4,6,8\}$ ($4$). The zero cannot be first: it stands in the 2nd or 3rd place ($2$), the $1$ in one of the two remaining ($2$), the last free place: $8$. Total $4\cdot 2\cdot 2\cdot 8=128$.
    $192+128=320$

6. On the exam

  • Conditions first: fill the boxes with restrictions (first digit $\ne 0$, parity, divisibility) at the beginning. The reverse order gives “it depends” and mistakes.
  • Zero in the first place is the most common trap in $n$-digit numbers.
  • Cases must be disjoint and exhaustive. Write them out explicitly (“last $0$” / “last $2,4,6,8$”), because that is what earns points.
  • “At least one” is almost always faster by the complement: all minus none.
  • Write a short description of each factor (e.g. “$8$: a digit $\ne 0$ and different from the last”). A bare product without comment may be graded $0$ points.
