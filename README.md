# Matematyka krok po kroku

Strona do nauki matematyki na poziomie matury rozszerzonej (podstawa programowa 2024): wszystkie działy z wyjaśnieniami, interaktywnymi animacjami, zadaniami z automatycznym sprawdzaniem, brudnopisem i powtórkami.

**Strona:** https://kar1kk.github.io/matematyka/

- Działa w przeglądarce na komputerze i telefonie; można ją zainstalować jako aplikację i używać bez internetu.
- Postęp nauki zapisuje się tylko w Twojej przeglądarce (można go zapisać do pliku i wczytać na innym urządzeniu).
- Wzory renderuje [KaTeX](https://katex.org) (licencja MIT, `assets/katex/LICENSE`).

**English:** https://kar1kk.github.io/matematyka/en/ — the whole site is also available in English (switch with the EN/PL button in the header).
